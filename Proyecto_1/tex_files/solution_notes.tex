\subsection*{Unbounded problem}
In iteration 4 the variable $x_{3}$ has an improving coefficient in the $Z$ row ($-6.0000$), but all the entries of its column in the constraint rows are $\le 0$. Therefore the ratio test has no candidate row and $x_{3}$ can grow indefinitely without violating any constraint, improving $Z$ without limit. The problem has no finite optimal solution.
