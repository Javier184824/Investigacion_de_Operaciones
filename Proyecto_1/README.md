* This project consists of the execution of the Simplex algorithm and to create a graphical
user interface for someone that wants to solve a system of equations with restrictions

* The user interface was made with Glade for creating the design and GTK to give the logic
of the program

* The program was written in the C Programing Language and the output of the program is an
LATEX stylize PDF document with the explanation of the solution of the problem given by the user
in the graphical interface

* The program supports a maximum of 15 different variables of decision and maximum of 15 
different restrictions of the kind "less or equal than". For the other inequalities, they 
will be implemented in the next version

* For the decision variables and restrictions, the minimum is 2

* The program supports for floating point numbers

* Depending on the input problem, the output will vary, but if the problem was randomly inputed
and the amount of variables and restrictions are big, the output, most of the time, will result
in a unbounded problem or unfeaseable
