* Esta tarea trata de resolver una serie de problemas que se tienen que usar el método Símplex, en donde
las soluciones que se ocupan obtener tienen que ser enteros. Para eso se tiene que juntar el algoritmo de 
Branch & Bound y el Símplex para obtener y descartar posibles soluciones enteras.

* Los problemas están resueltas en el documento de PDF que se encuentra en la carpeta de output. No es
necesario compilar el archivo de Latex, pero si se requiriera, solamente se tiene que correr el comando:

```
make pdf
```

Esto compila el archivo main.tex y lo compila a través de pdflatex y el resultado se guarda en la carpeta
output.

También está el comando para limpiar la carpeta output:

```
make clear
```
